# 09 · Glossary

| Term | Meaning |
|---|---|
| GCC | Gulf Cooperation Council: Kuwait, Saudi Arabia, UAE, Qatar, Bahrain, Oman |
| KNET | Kuwait's national debit card network, the most-used online payment method in Kuwait |
| mada | Saudi Arabia's national debit network |
| BenefitPay | Bahrain's national payment app / network |
| RTL | Right-to-left layout (Arabic, Urdu) |
| Fils / Halala / Baisa | Minor currency units (KWD & BHD: 1000 fils; SAR: 100 halala; OMR: 1000 baisa) |
| DDP / DDU | Delivered Duty Paid (seller pays import duties) / Delivered Duty Unpaid (recipient pays) |
| HS code | Harmonized System code that classifies goods for customs |
| IEC | Import Export Code (India, issued by DGFT) |
| LUT | Letter of Undertaking that lets Indian exporters ship without paying IGST |
| GI tag | Geographical Indication, a legal protection for region-specific products (e.g. Nizamabad Black Pottery) |
| Eidiya | Gift / money given at Eid |
| Region (Medusa) | Commerce config per market: currency, tax, payment and shipping |
| PWA | Progressive Web App, a website installable like an app |
| BNPL | Buy now, pay later (Tabby, Tamara) |
| Hub | Stock location inside a GCC country for fast local delivery |
