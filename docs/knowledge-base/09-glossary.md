# 09 · Glossary

| Term | Meaning |
|---|---|
| RTL | Right-to-left layout (Arabic, Urdu) |
| GI tag | Geographical Indication, a legal protection for region-specific products (e.g. Nizamabad Black Pottery) |
| Eidiya | Gift / money given at Eid |
| PWA | Progressive Web App, a website installable like an app |
| BNPL | Buy now, pay later (Tabby, Tamara) |
| UPI | Unified Payments Interface: India's instant bank-to-bank payments (GPay, PhonePe, Paytm) |
| COD | Cash on Delivery |
| RTO | Return to Origin: undelivered parcel sent back (common with COD) |
| PIN code | India's 6-digit postal code |
| GST / HSN | Goods & Services Tax / code that classifies goods for GST |
| Razorpay | Indian payment gateway (UPI, cards, payment links) |
| Shiprocket | Indian shipping aggregator (Delhivery, Blue Dart, Xpressbees…) |
