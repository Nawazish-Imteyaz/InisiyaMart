# 003 · Brand identity: Mehrab & Surahi, Urdu wordmark

- **Date:** 2026-11-03
- **Status:** proposed as the recommended final (awaiting owner sign-off)
- **Context:** Owner pointed out that Azamgarh speaks **Urdu, not Arabic**, and asked for one best recommendation.
- **Decision:**
  - Logo = **Mehrab & Surahi** (gold arch + black-pottery surahi), merging directions 1 and 2.
  - Wordmark scripts: **INSI HOUSE** + Urdu Nastaliq **انسی ہاؤس**. The earlier Arabic name «بيت إنسي» is retired from the logo.
  - Palette Kohl / Zari / Ivory / Plum / Silver. Full spec in `docs/brand/colors-fonts.md`.
  - Collections named with words shared by Urdu and Arabic: Tohfa, Nafees, Zauq, Khuloos.
- **Consequences:**
  - The website still needs a full **Arabic-language version** for GCC customers (they don't read Urdu sentences). Urdu is used in the brand, logo, packaging and storytelling, and an Urdu site language is optional (P2).
  - Urdu and Arabic text need native review before print.
